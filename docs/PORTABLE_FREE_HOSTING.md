# Portable NFT Console runtime deployment

GitHub Actions can build and publish this repository as an immutable OCI image under `ghcr.io/neophilism/nft-minting-console:sha-<main-commit>`, using Node 22.20, compiled Solidity contract artifacts and the current real Vite web interface. The runtime starts `console/runtime.mjs` on `0.0.0.0:3000`. Build-on-merge occurs for this new infrastructure workflow; future releases are manually dispatched. There is no host, credit card, database cloning, or Ethereum action initiated by an image build.

**To relocate to an authorized free container host**, configure its private environment with `HOST=0.0.0.0`, `PORT=3000`, `NODE_ENV=production`, the exact HTTPS `PUBLIC_ORIGIN`, the existing restricted Neon `DATABASE_URL`, mainnet `CHAIN_ID=1`, `RPC_URL` from Alchemy or a verified compatible provider, `PINATA_JWT` in backend secrets only, `NFT_PUBLIC_LAUNCH=1`, and `NFT_MAINNET_ACK=ethereum-mainnet-real-fees` only when the owner has reviewed real Ethereum gas and signing responsibility. When not yet installed and using browser enrollment, use `NFT_SETUP_ENABLED=1` with random 64-character `NFT_SETUP_CODE`, not an all-wallet allowance. **Never copy database migration owner credentials or private wallet seeds** to the host. Apply migrations only through the audited one-time migration procedure before the runtime is started; this image does not automatically mutate the database. Existing project reference: `dark-math-52213387`.

After hosting, independently verify `/api/health`, `/api/setup/status`, `/api/config`, public UI, RPC network, restricted DB, private Pinata operations (with deliberate user-provided public files), and the owner-approved cost/rights before any Ethereum transaction. A working site alone does not mint a token. The owner must perform and approve each wallet signing transaction, including any gas costs.

This package preserves the original production code; it is not a claim of full product completion or live marketplace listing. See `docs/MINT_INPUT_CHECKLIST.md` and `docs/BROWSER_INSTALLATION.md`.
