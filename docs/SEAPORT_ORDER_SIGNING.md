Seaport 1.6 order preview and direct EOA signing component. Never automatically signs or submits. The caller must verify current chain, Seaport counter, NFT custody, ERC721C transfer policy, operator approval, complete fees/royalties and explicit review consent before enabling the wallet click. Pure preview always states productionReady=false; signReviewedEOA requires confirmed=true and checks chain/account/signature. Browser UI and Safe ERC1271 support are outstanding. No real signatures or funds used in tests.
Sources: https://github.com/ProjectOpenSea/seaport-js and https://github.com/ProjectOpenSea/seaport-types
