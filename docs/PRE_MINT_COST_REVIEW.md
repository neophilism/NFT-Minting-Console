# Total cost review before signing

The Deploy & mint page has a read-only **Estimate total minting cost** panel. Enter or load collection settings below it, import all already-published public mint bundles, approve their readback, and the read-only whole-release rehearsal starts automatically. Use **Re-run rehearsal and cost estimate** only to request a fresh quote. A new collection quote includes its deployment plus every supplied mint batch. An existing verified collection quote rechecks its original deployment and current immutable configuration, then quotes only the remaining supplied mints; it never charges for deployment again.

The UI displays simulated network-fee estimate, a separate fee budget using the wallet's upward-rounded 20% gas-limit margin, per-operation breakdown, per-wallet balance/shortfall and aggregate additional funds needed. One wallet balance is subtracted once, not per batch. There is no USD conversion or invented service charge. Pinata/hosting/database/RPC subscriptions, marketplace approvals/orders, transfer-policy changes and exchange/bridge costs are excluded and explicitly unknown, not zero. Public upload costs may precede the mint quote.

These are current-price estimates, not guaranteed final bills. Quotes expire after two minutes and disappear when files, collection settings, network, wallet or selection change. The automatic quote runs once per consented, unchanged input snapshot. A failed or unavailable simulation stays failed until the owner deliberately retries; no second wallet signature is needed for a read-only rehearsal. Exact paid gas is known only after execution. The quote is never an authorization token: all existing independent wallet simulation, fee confirmation and explicit signatures remain required. No quote uploads a file, reserves a transaction, mutates the launch journal or sends a blockchain transaction.

The API is owner-authorized and origin/CSRF protected using the existing deploy action. It validates every bundle, immutable field and file commitment, rejects duplicate token IDs and conflicting public-file commitments, deduplicates readback, then uses the actual `eth_simulateV1` engine. It supports at most 500 supplied works, batches of ten, and 8 MiB total JSON. At most two quote jobs per server process run concurrently, with one per wallet/chain, a bounded deadline and cancellation. Provider limits can be lower. Missing sequential simulation or peak-gas measurements produce an explicit unavailable result, never a partial or zero total.

The existing pinned Geth fixture exercises new-collection simulations with shared/separate signers and multiple batches. The added existing-collection fixture deploys and mints one synthetic token only on that private local chain, then proves quoting the remaining eleven across two batches changes no source balance, nonce or head. HTTP/model tests cover input rejection, authorization action binding, exact totals and expiry. Browser tests explicitly model the quote response to verify display, consent, input invalidation, accessibility and lack of wallet sends; they are not misrepresented as a production-RPC test.
