CREATOR TOOLS

NFT Console

New collections, permanent rights, files and minting without command lines.

1. New release

Deploy once per release. The wallet pays gas. Configure marketplace permissions with a tested validator before selling.

2. Add NFTs

Choose one media file for multiple editions, or one file per NFT (up to 10 per batch).

3. OpenSea

After minting, open the NFT on OpenSea and complete the required owner approvals and listing signature. The console does not claim a listing exists until an actual marketplace order has been submitted and verified.

No private keys are stored. All on-chain operations require explicit wallet signatures. The wallet must be the contract's MINTER to mint.
